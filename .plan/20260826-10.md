# 原生 Docker 管理面板与一键更新

## 目标

为 `new-api-lite` 提供不依赖 Docker Compose 的 Bash 管理脚本，使管理员可通过交互式菜单或明确的子命令安全地安装、更新、查看、停止、重启和卸载容器，并始终保留 SQLite 数据目录，除非管理员输入强确认执行数据删除。

## 安全边界

| 项目 | 约束 |
| --- | --- |
| 容器 | 仅操作名称为 `new-api` 的容器，不运行全局 prune。 |
| 数据 | 默认使用执行目录的 `./data`；更新与卸载均保留数据目录。 |
| 删除数据 | 仅 `remove-data` 操作可执行，拒绝 `/` 与用户主目录，且必须输入 `DELETE`。 |
| 架构 | 启动时显示系统发行版与 CPU 架构；默认多架构 `latest` manifest 由 Docker 自动解析为 ARM64 或 AMD64 变体。 |
| Docker | 检查客户端、守护进程和当前用户权限；若无 Docker，在 `install`/`update` 通过 `apt-get`、`dnf`、`yum` 或 `apk` 自动安装并尝试启动。 |
| 镜像 | 默认 `ghcr.io/55gy/new-api-lite:latest` 多架构 manifest，可通过 `NEW_API_LITE_IMAGE` 覆盖。 |
| 更新 | 先准备 Docker、拉取镜像，再删除旧容器，最后使用相同端口、时区和挂载路径创建容器。 |
| Lite 约束 | 不引入计费、额度、倍率、音视频或任务功能；仅增加运维脚本和文档。 |
