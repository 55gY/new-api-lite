# staticcheck 第五批语义等价修复计划

## 范围

本批只包含 nil slice 遍历、布尔比较等价化简，以及一个确认无调用方的控制台设置正则残留；未涉及迁移、缓存/额度、协议 DTO 或 API 错误文本。

## 实施与验证

| 项目 | 结果 |
| --- | --- |
| Claude 工具 token 统计 | 删除 `normalTools` 和 `webSearchTools` 的冗余 nil 守卫；nil slice range 仍是零次迭代。 |
| Token IP allowlist | 将 `== false` 改为 `!`，拒绝分支不变。 |
| 控制台校验 | 删除无读取方的 `slugRegex`，保留 URL 校验所需 `urlRegex`。 |
| 定向测试 | `go test ./dto ./middleware ./setting/console_setting` 通过。 |
| 完整隔离回归 | Bun 生产构建、Go 全量测试、`go build -trimpath`、`go vet`、全库 `go test -race` 均通过。 |
| staticcheck | 物理日志行由 108 降至 104。 |

## 保留边界

剩余 U1000 的 quota/cache/TTS、迁移/perf、adapter 协议类型和对外错误文本继续待专项验证，不使用 ignore 掩盖。
