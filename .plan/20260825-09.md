# staticcheck 第三批语义等价修复计划

## 目标与边界

本批仅处理不改变 API、数据模型、错误文本或业务分支的布尔返回化简。未触及弃用路由、响应写失败语义、迁移/cache/额度及协议 DTO。

## 实施与验证

| 项目 | 结果 |
| --- | --- |
| `common/embed-file-system.go` | 文件存在性判断直接返回 `err == nil`。 |
| `dto/claude.go` | Claude 内容字符串类型判断直接返回 type assertion 结果。 |
| `dto/openai_request.go` | OpenAI 消息字符串类型判断直接返回 type assertion 结果。 |
| 定向验证 | `go test ./common ./dto` 通过。 |
| 完整隔离验证 | Bun 生产构建、Go 全量测试、`go build -trimpath`、`go vet` 与全库 `go test -race` 均通过。 |
| staticcheck | 物理日志行由 124 降至 121。 |

## 保留项

其余 S100x/S102x 项仍按包和功能域分批处理，避免大范围格式化差异。任何 error 文本、public API、路由、数据库迁移和上游协议签名均不因风格规则自动修改。
