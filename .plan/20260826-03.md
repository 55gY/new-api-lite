# U1000 A 批立即删除清理计划

## 范围校正

此前 A 批文字说明称“12 项”，但逐一核对后该组实际包含 **11 个符号单元**：4 个控制器/模型残留、2 个 Gemini helper、2 个 OpenAI helper、1 个 TTS helper、1 个 Volcengine helper、以及 1 个 Claude 常量块（内含 3 个常量）。本批按实际符号单元全部执行，未擅自扩展到协议 DTO 或 quota/cache 候选。

## 已删除项

| 域 | 删除内容 |
| --- | --- |
| 控制器/模型 | `generateDefaultSidebarConfig`、旧 `getPriority/getChannelQuery`、`logSearchCountLimit`。 |
| Gemini | 已不再调用的手工 `unescapeString/unescapeMapOrSlice`。 |
| OpenAI | Responses 旧流 key/delta helper，以及已删除 audio API 的 `streamTTSResponse`。 |
| Volcengine | 无调用方的图片 MIME 推断 helper。 |
| Claude 转换 | 未接入的 OpenRouter web-search max uses 常量块。 |

## 验证

- 删除过程中清理了 Gemini `utf8` 和 Volcengine `filepath` 两个专属遗留 import。
- 已运行控制器、模型、Gemini、OpenAI、Volcengine、Claude 转换的定向测试。
- 最终隔离副本通过 Bun 生产构建、`go test ./...`、`go build -trimpath ./...`、`go vet ./...` 和 `CGO_ENABLED=1 go test -race ./...`。
- staticcheck 物理日志行由 36 降至 **23**，U1000 从 36 降至 **23**。
