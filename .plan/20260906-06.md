# 模型限流开关模板对齐计划

## 根因复核

对比同页“启用用户模型请求速率限制”后确认，新增开关需要使用相同的 `Form.Switch` 结构、`field={'...'}` 写法和直接 `setInputs({ ...inputs, ... })` 触发方式。Semi UI 的 `describedby` 由 `extraText` 生成，是无障碍说明属性，本身不会改变开关值；真正影响开关显示和保存的是父组件对后端字符串布尔值的转换。

## 实施内容

本次将全局 API、全局 Web、关键接口和搜索四个开关改为与模型限流开关一致的 JSX 模板；敏感词停止策略开关也同步采用同样模板。速率限制父组件已经按初始状态字段类型调用 `toBoolean`，因此 `Enable` 与 `Enabled` 字段都会传给 `Form.Switch` 真正的布尔值。

后端 `go test ./model ./middleware ./controller ./setting/...` 通过，目标 JSX 文件的 Prettier 检查通过，`git diff --check` 通过。当前修复只保留在本地，未执行远程推送。
