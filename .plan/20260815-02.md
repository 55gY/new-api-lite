## Current State

项目当前具备渠道管理、渠道上游模型更新和 Codex 凭据刷新等后台维护能力，但没有通用的管理员可配置签到任务实体、执行日志、渠道关联或相应的管理界面。`AGENTS.md` 原先禁止异步任务和额度功能，因此需增加针对“用户授权的第三方渠道签到”这一受限用途的显式例外。

## Target State

管理员可以创建、编辑、启停并手动运行签到任务；渠道新增/编辑时可选择关联一个已有签到任务。任务只对管理员明确配置的 HTTPS 请求地址发送受认证请求，支持系统访问令牌或 Cookie、用户 ID、固定出站代理、超时和有限网络重试。出现验证码页、WAF/反爬响应、401、403 或不可识别 HTML 页面时，任务停止并进入“需人工处理”状态，记录脱敏原因，不尝试绕过或伪装。

## 安全边界

| 允许 | 明确不允许 |
|---|---|
| 管理员提供的 HTTPS 签到 URL、系统访问令牌或 Cookie、用户 ID。 | 验证码、WAF、反爬或 Cloudflare 绕过。 |
| 管理员明确配置的单一固定代理，且仅用于常规网络连通性。 | 代理轮换、自动切换、地域/指纹伪装或规避访问限制。 |
| 有上限的网络错误重试、超时、TLS 校验、私网/环回地址拦截。 | 对 401、403、验证码页、风控页或 HTML 拦截页进行重试规避。 |
| 脱敏日志、人工处理状态、手动更新 Cookie/令牌后重试。 | 账号密码/OAuth 自动登录、CDK/充值、第三方额度读取/存储/计算。 |

## Rollback Plan

本功能将以新增实体、独立服务和可选渠道关联实现。回滚时先停用调度器和路由入口，再删除/回退签到任务前端入口及服务调用；渠道关联字段保留为 `NULL` 兼容值，不影响已有渠道转发。

## Risks

- 第三方站点会变更签到接口、令牌格式或响应结构；任务应显示明确的配置/人工处理状态，而非自行绕过。
- Cookie 与系统访问令牌属于敏感凭据，必须加密持久化、脱敏展示并避免进入日志、错误消息和前端状态。
- 需要限制请求目标，防止管理员误配置导致 SSRF 访问私网或云元数据地址。
- 固定代理的可达性和权限由管理员负责；任务不得以代理失败为由切换或伪装网络身份。
