# 全局 API 限流设置开放计划

## 执行规则

本计划遵循仓库 `AGENTS.md` 的项目调整计划规则。每完成一个步骤更新 checkbox；每完成一个 Phase 重新读取 `plan.md` 并记录下一阶段；提交说明使用简体中文；不引入计费、额度、倍率、音视频或异步任务功能。

## Current State

全局 API 限流已由 `middleware.GlobalAPIRateLimit()` 挂载到 `/api` 路由，但启用开关、请求数量和时间窗口主要由环境变量初始化，前台系统设置不能控制，且开关默认值为启用。

## Target State

在速率限制设置页面开放全局 API 限流开关、周期内请求次数和周期秒数；配置保存后动态更新内存值；默认关闭；保留现有环境变量作为初始默认值来源，不改变其他限流类型。
