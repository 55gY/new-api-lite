# 限制配置开关模板对齐修复计划

## 执行规则

本计划遵循仓库 `AGENTS.md`。本次只在本地修改、测试并创建中文提交；除非用户明确要求，不执行远程推送。

## 根因

速率限制父组件原先只对 `Enabled` 后缀调用 `toBoolean`，而今天新增的开关使用 `Enable` 后缀，因此 API 返回的字符串 `"false"` 被直接传给 `Form.Switch`。字符串在控件中属于真值，导致开关显示和点击行为异常，保存刷新后也无法稳定禁用。用户观察到的 `describedby` 是 `extraText` 生成的无障碍描述属性，不是保存失败的根因。

## 修复内容

将速率限制父组件的选项转换改为参照“默认折叠侧边栏”的通用模板，按初始状态字段的布尔类型调用 `toBoolean`，覆盖所有新增 `*Enable` 和既有 `*Enabled` 开关。新增限流开关及敏感词停止策略开关同时补齐 `size`、`checkedText` 和 `uncheckedText` 参数，使 Form.Switch DOM 结构与通用模板一致。

`go test ./model ./middleware ./controller ./setting/...`、`git diff --check` 和目标 JSX 文件的 Prettier 检查均通过。前端完整构建仍受项目基线缺少 `@douyinfe/semi-illustrations` 依赖影响，本次没有改动该无关依赖。当前只创建本地提交，不推送远程。
